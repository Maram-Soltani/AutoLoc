# AutoLoc 🚗

## Description
AutoLoc est une application de gestion de location de voitures. Elle permet de gérer les agences, les clients, les véhicules, les réservations, les contrats, les paiements et les opérations de maintenance.

## Technologies utilisées
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger / OpenAPI
- Postman

## Fonctionnalités
- Gestion des agences
- Gestion des clients
- Gestion des véhicules
- Gestion des réservations
- Gestion des contrats
- Gestion des paiements
- Gestion de la maintenance

## Architecture
Le projet utilise une architecture en couches :
- Entity
- Repository
- Service
- Controller

## Installation
1. Cloner le projet :
   `git clone https://github.com/Maram-Soltani/AutoLoc.git`
2. Ouvrir le projet dans IntelliJ IDEA.
3. Configurer la base de données MySQL dans `application.properties`.
4. Exécuter l'application Spring Boot.
